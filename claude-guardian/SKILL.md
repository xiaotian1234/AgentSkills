# Claude Guardian（本地只读版）

这是基于上游用途重新编写的本地受限变体，不是原版完整安装，也不是 Anthropic 官方工具。来源、改动和证据边界见 [来源与限制](references/origin-and-limits.md)。

## 启用边界

仅在用户明确调用本技能时使用，不自动接管其他 Claude 问题。安装不代表允许检测；调用后先按用户本次请求确定范围。只问使用方法时，不扫描本机、不联网。

不包含原版脚本、后台服务、自动修复或清理能力。不要为了补齐能力而下载、运行原版脚本，也不要临时编写替代修复脚本。

## 工作流程

1. 确认问题是订阅资格、付款失败、客户端报错还是网络连通性。只询问缺失且必要的信息：实际所在地、目标产品/购买渠道、错误原文。不要把时区或出口 IP 当作实际所在地。
2. 区分三个结论，分别记录已知证据和未知事项：
   - 资格：所在地、产品开放范围、账号条件，以当前官方政策为准。
   - 付款：官方支持的支付方式、账单信息与购买渠道。只给说明，由用户自行登录和支付。
   - 网络：系统配置或指定目标的连通性。网络可达不等于具备订阅资格，也不保证账号安全。
3. 用户明确要求本机只读检查时，仅检查指定范围内最少信息，例如 Windows 版本、当前用户代理启用标志、是否存在 PAC 配置。只输出摘要，不输出代理凭据或完整订阅/PAC URL。不要广泛扫描其他账号、历史记录或日志。
4. 联网检测需先说明目标域名、用途和将发送的信息，并取得该范围的明确许可。未获许可时停留在本地只读检查或解释现有报错。不得绕过代理、权限或受限网络，不进行断网、故障注入或账户登录测试。
5. 解释当前政策时，核对官方原文及生效日期。若无法获取，明确标注尚未核实，不把记忆或社区帖子当现行政策。社区经验必须标明来源、日期和不确定性。

## 禁止事项

- 不改系统代理、TUN、DNS、IPv6、防火墙、路由、SSH、PATH、浏览器指纹、时区或客户端状态。
- 不安装依赖/服务，不加开机启动，不重启程序或机器，不清理、删除、移动账号文件。
- 不读取凭据文件、Cookie、会话令牌、私钥、支付资料或完整代理配置；不要求用户粘贴这些信息。
- 不代为注册、登录、验证码验证、绑定银行卡、下单、支付或退款。
- 不提供绕过地区、身份、支付验证或平台限制的操作；不把换号、养号或逃避 KYC 当作解决方案。
- 不把“IP 干净”“全绿”“IPv4 only”作为可订阅或不会封号的证明。IPv6 本身不是故障，不据此建议禁用。
- 不承诺订阅成功率、退款率或账号稳定率；明确检测能证明和不能证明的事项。

## 输出

简要给出：结论、已核实的证据、仍未知的条件、用户可自行执行的下一步。未检查的项目写“未检查”，不生成虚假的通过结果。对超出只读边界的请求，说明本技能不执行该操作，不把安装许可扩展为系统修改许可。

只读是一组行为约束，不是操作系统沙箱；使用云端模型分析诊断信息也不等于完全离线。避免收集或复述不必要的个人信息。
