## 核心框架 1：几何层级诊断框架

来源：第 1-3 章，第 6-10 章，第 19 章，第 21 章。

适用场景：双目/多目项目中，算法输出“看起来有 3D”，但尺度、姿态、深度正负、机器人坐标系或测量单位不可信。

核心思想：任何 3D 结果都先问“恢复到了哪一层几何”：projective、affine、metric/Euclidean，还是已经进入机器人工作坐标系。不要把未经约束的投影重建当成可测量三维。

步骤：

1. 定义输入观测：图像点、线、平面、标定板角点、机器人位姿、IMU/编码器、CAD 平面或已知距离。
2. 确认相机模型：针孔/有限相机、无穷远相机、径向畸变、内参是否固定、外参是否随时间变化。
3. 判断当前可恢复层级：只有匹配点且未标定时，默认只能得到 projective reconstruction；已知内参或足够标定约束时，才推进到 Euclidean reconstruction。
4. 明确缺失约束：尺度、平面无穷远、绝对二次曲线、正深度、基线长度、机器人手眼关系、世界坐标系原点。
5. 用 cheirality 和物理约束筛除候选解：所有可见点应落在相机前方；机器人引导还要满足工装、相机安装和运动学约束。
6. 输出“几何状态报告”：当前层级、已知量、未知量、可测量量、不可测量量、下一步需要采集的数据。

输出物：

- `geometry_state.md`：相机模型、坐标系、恢复层级、尺度来源、正深度验证、退化风险。
- `constraint_gap.md`：要达到可交付精度还缺什么约束。

## 核心框架 2：估计-鲁棒-优化流水线

来源：第 4-5 章，第 7 章，第 11-13 章，第 16 章，第 18 章，附录 3-6。

适用场景：计算单应性、基本矩阵、相机矩阵、三角化点云或多视图 bundle adjustment，尤其面对误匹配、噪声、视差不足和数值不稳定。

核心思想：多视图几何不是“套公式”，而是一条估计流水线：规范化数据 -> 线性初值 -> 约束投影 -> 鲁棒筛选 -> 几何误差优化 -> 协方差/残差评估。

步骤：

1. 数据预处理：去畸变或显式建模畸变；统一像素坐标约定；剔除重复点、近共线点、低置信匹配。
2. 坐标 conditioning：对图像点做平移与尺度规范化，降低 DLT、8 点法、三角化的病态风险。
3. 线性估计初值：H 用 DLT；F 用归一化 8 点法或 7 点法；P 用点-3D 对应；X 用线性三角化。
4. 强制几何约束：F 应为 rank 2；E 应满足本质矩阵约束；旋转矩阵应回到 SO(3)；深度应满足 cheirality。
5. 鲁棒估计：用 RANSAC 或等价鲁棒策略处理外点，并把内点阈值绑定到测量噪声和镜头分辨率，而不是拍脑袋。
6. 几何误差优化：用 reprojection error、Sampson approximation 或 MLE 风格目标替代纯代数误差作为最终准则。
7. 误差解释：输出 RMS/median/max reprojection error、内点率、参数协方差或置信区间、空间误差随深度的变化。
8. 多视图收尾：两视图结果稳定后，再进入多视图 BA；固定哪些参数、优化哪些参数必须写明。

输出物：

- `estimation_report.json`：模型类型、样本数、内点数、阈值、误差统计、退化检测结果。
- `reconstruction_bundle`：相机参数、点云、每点重投影误差、每相机外参误差、失败帧列表。

## 核心框架 3：模型选择与退化排查框架

来源：第 4.8、9-13、18、22 章。

适用场景：机器人引导、平面定位、双目测量中，H、F、E、PnP、三角化都能跑，但结果互相矛盾或上线后间歇性失败。

核心思想：先判断场景几何，再选模型。平面或纯旋转优先单应性；有足够视差和非共面结构才依赖极线几何与三角化。许多“算法不准”其实是场景退化或约束不够。

步骤：

1. 判断场景主结构：平面、近似平面、一般 3D、远景/弱视差、纯旋转、平移为主、重复纹理。
2. 同时试算候选模型：H、F/E、PnP/相机矩阵、三角化，比较内点集合是否互相包含或冲突。
3. 做退化测试：共面点、低视差、相机中心近共线、基线过短、点分布集中、重复纹理导致假匹配。
4. 选择最小可信模型：若 H 解释绝大多数匹配且三角化深度不稳定，先交付平面定位；不要硬做 3D。
5. 对机器人项目增加工况扫描：距离、视角、光照、工件姿态、遮挡、运动模糊、镜头温漂。
6. 输出模型选择结论：推荐模型、弃用模型、弃用理由、需要补采的数据。

输出物：

- `model_selection_report.md`：H/F/E/PnP/triangulation 的适用性比较。
- `degeneracy_tests.csv`：每组图像的视差、点分布、内点率、正深度比例、重投影误差。

## 决策规则

1. 如果项目要求真实长度、机器人抓取位姿或 CAD 对齐，则必须追踪尺度来源；只有未标定图像匹配时，不得承诺 metric/Euclidean 精度。（第 1、3、10、19 章）
2. 如果场景主要是平面、传送带平面、标定板平面或相机纯旋转，则优先用 homography 建模；不要把低视差场景强行三角化成 3D。（第 4、9、11、13、22 章）
3. 如果估计 H、F、P 或三角化点使用线性算法，则先做坐标归一化/conditioning，再估计，再反归一化；未经 conditioning 的 DLT/8 点法结果只能当快速试算。（第 4、11、12 章，VGG code）
4. 如果匹配含外点，则线性最小二乘不能作为最终算法；必须用鲁棒估计筛内点，并报告阈值、内点率和失败样本。（第 4.7、4.8、11.6、16.6 章）
5. 如果最终用于精度交付，则优化目标应从代数误差切换到几何误差或重投影误差；代数误差低不等价于几何精度高。（第 4.2-4.5、5、7.2、11.3-11.5、12.3-12.5、18.1 章）
6. 如果由 F 或 E 恢复相机姿态/结构，则必须做 cheirality 检查；不能只看矩阵分解是否成功。（第 9.5、9.6、10、21 章）
7. 如果使用 fundamental matrix，则默认它只表达两幅图像之间的 projective 关系；只有加入内参 K 后，才进入 essential matrix 与欧氏相对位姿问题。（第 9.2、9.5、9.6、10 章）
8. 如果标定结果用于三维测量，则畸变模型、坐标系定义、棋盘/靶标平面质量和重投影误差分布必须进入验收；单个平均误差不能代表全视野精度。（第 5、6、7、8 章）
9. 如果两视图重建不稳定，则先检查基线、视差、点分布、共面性和重复纹理，再调参；这类问题通常不是优化器本身能补救的。（第 11.9、12、22 章）
10. 如果多视图系统已经有稳定初值，则用 bundle adjustment 做联合优化；不要把每对相机独立估计后简单拼接成全局 3D。（第 18.1 章）

## 检查清单 1：双目/3D 项目上线前几何审查

来源：第 5-13、18、21-22 章。

- [ ] 相机模型写清：针孔、畸变、内参是否固定、焦距是否变动、曝光/滚动快门风险。
- [ ] 坐标系写清：图像坐标、相机坐标、世界坐标、机器人基坐标、工具坐标之间的变换方向和单位。
- [ ] 标定数据覆盖真实工作距离、视角、景深和视场边缘。
- [ ] 每台相机有内参、畸变参数和重投影误差分布；不只记录平均值。
- [ ] 双目外参有基线长度、旋转、尺度来源和物理安装复核。
- [ ] F/E/H/PnP/三角化的输入匹配有数量、分布、内点率和外点处理记录。
- [ ] 已做 cheirality 检查：有效点应在相机前方，异常点有解释。
- [ ] 已做退化检查：共面、近共面、低视差、点集中、重复纹理、纯旋转、相机中心近共线。
- [ ] 最终误差用重投影误差和业务误差双重表达：像素误差 + 毫米/角度/抓取成功率。
- [ ] 有重标定触发条件：温漂、撞机、镜头调焦、相机拆装、工装更换、长期漂移。

## 检查清单 2：平面定位/Homography 项目审查

来源：第 4、8、13 章。

- [ ] 确认目标确实可近似为同一平面，或相机运动接近纯旋转。
- [ ] 特征点覆盖整个平面，避免集中在一条线、一角或重复纹理区域。
- [ ] 使用 normalized DLT 或等价 conditioning；估计后检查反投影误差。
- [ ] 用鲁棒估计剔除误匹配，并保存内点 mask。
- [ ] 若从 H 分解姿态，记录尺度/符号/正深度歧义如何消除。
- [ ] 若用于机器人抓取，验证平面外高度变化对末端误差的影响。
- [ ] 若实际工件有厚度、翘曲或非平面特征，给出误差预算或切换到 3D/PnP。

## 反模式

1. 把 calibration 当成一次性仪式：拍几张标定板得到 K 和畸变就结束，不检查视野边缘、工作距离、温漂和重投影误差分布。（第 5-8 章）
2. 把 fundamental matrix 当成位姿：F 本身不提供唯一欧氏相机位姿；未引入 K 和 cheirality 前，位姿解释是不完整的。（第 9-10、21 章）
3. 只看平均 reprojection error：平均值会掩盖边缘畸变、局部坏点、退化姿态和少量灾难性外点。（第 5、7、11、12 章）
4. 在平面/低视差场景硬做稠密 3D：数值上可能输出点云，几何上却缺少足够深度约束，机器人使用会表现为距离漂移。（第 10-13、22 章）
5. 独立 pairwise 拼接多相机：每对估计都看似合理，但全局尺度、闭环一致性和相机网络约束会累积冲突；应进入全局优化或 BA。（第 18 章）

## 边界声明

- 本方法论适合经典多视图几何、相机标定、双目测量、平面定位、机器人视觉引导和 SfM/BA 的工程判断；不等价于完整 SLAM 系统设计方法。
- 本书第二版出版于 2004 年，深度学习式单目深度、NeRF/3D Gaussian Splatting、端到端视觉里程计、神经重建不在其主干覆盖范围内。
- 本书强调中心投影、投影几何和估计理论；对工业镜头的复杂畸变、滚动快门、事件相机、ToF/结构光硬件误差模型覆盖有限。
- 几何方法依赖可观测约束。纹理贫乏、反光透明、强重复纹理、运动模糊、低基线、强遮挡场景中，理论可解不代表工程可交付。
- 从书中章节提炼的规则需要结合具体库实现核对公式和勘误；实现前应查看 VGG errata 与所用开源库文档。

## 适用场景

- 双目相机做尺寸测量、深度估计、点云重建、机器人抓取位姿估计。
- 多相机或移动相机做 SfM、相机外参恢复、三维结构重建。
- 传送带、标定板、工件平面、AR 贴图等平面 homography 项目。
- 标定结果验收、几何误差诊断、外参漂移排查。
- 在 OpenCV、HALCON、Ceres/g2o、ROS 工程中设计几何算法链路和验收指标。

## 不适用场景

- 只依赖单张自然图像估计绝对尺度且无任何先验的任务。
- 主要问题是识别、检测、分割、OCR、缺陷分类，而不是几何关系恢复。
- 端到端深度学习模型训练、数据标注策略、GPU 推理部署优化。
- 透明/镜面/弱纹理物体的 3D 感知若无主动光、偏振或多模态传感器辅助。
- 要求安全认证级机器人控制，但没有独立传感器冗余、机械限位和风险评估的系统。

## 工作流：收到项目问题后如何使用本方法论

1. 先问项目输出：要像素级对齐、平面位姿、相对位姿、真实 3D 尺寸，还是机器人末端动作。
2. 建立几何层级：当前信息只能支持 projective、affine、metric，还是已到机器人坐标系。
3. 选择模型：H、F、E、P/PnP、triangulation、multi-view BA，不同时满足时先做退化排查。
4. 制定采集方案：标定板/控制点/多视角/基线/光照/工件姿态覆盖。
5. 运行估计流水线：conditioning -> linear init -> robust fitting -> nonlinear geometric optimization -> error report。
6. 用检查清单验收：坐标系、尺度、畸变、正深度、退化、误差统计、业务误差。
7. 给出交付边界：哪些工况有效，哪些工况需要重标定、补光、换模型或加传感器。
