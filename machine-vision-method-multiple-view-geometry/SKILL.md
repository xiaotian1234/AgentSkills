# 《Multiple View Geometry》方法论

## 什么时候用我

- 双目、结构光、多相机、机器人引导、手眼标定、平面定位、3D 重建。
- 定位结果不稳、深度误差大、重投影残差异常、外参漂移。

## 核心框架

### 1. 几何层级诊断

按层级检查：像素坐标、归一化相机坐标、内参、畸变、外参、世界坐标、机器人坐标。任一层混乱，结果都会漂。

### 2. 估计-鲁棒-优化流水线

先估计初值，再用 RANSAC/鲁棒损失排外点，最后做非线性优化和重投影误差分析。

### 3. 模型选择与退化排查

平面用 homography，双目用 fundamental/essential matrix，3D 用 PnP/SfM/BA。检查共线、纯旋转、低视差、重复纹理、标定板姿态不足等退化。

## 决策规则

1. 平面定位优先检查 homography 假设是否成立。
2. 双目测量必须同时验证内参、外参、畸变、基线和同步。
3. 三角化精度受视差、基线、焦距、像素噪声共同影响。
4. 重投影误差要看分布和空间结构，不只看均值。
5. RANSAC 只能处理外点，不能修复错误相机模型。
6. 标定板姿态必须覆盖视野和角度变化。
7. 机器人引导必须验证相机坐标到机器人坐标的完整链路。
8. 低纹理、重复纹理和反光会破坏匹配。
9. 多相机系统要管理时间同步和机械刚性。
10. 任何 3D 结论都要报告单位、坐标系、误差和验证方法。

## 检查清单

- [ ] 坐标系定义完整：图像、相机、世界、机器人。
- [ ] 内参、畸变、外参、手眼链路都有验证。
- [ ] 标定样本覆盖视野、距离和角度。
- [ ] 有重投影误差图、外点比例和残差空间分布。
- [ ] 有真实尺寸或标准件验证。
- [ ] 有低视差、遮挡、反光和重复纹理 stress case。

## 反模式

- 坐标系混用。
- 只看标定 RMS，不看残差分布。
- 用 RANSAC 掩盖错误模型。
- 标定板姿态太少或太集中。
- 机器人引导不验证最终 TCP 误差。

## 边界

该方法论解决几何一致性和测量链问题，不替代机械刚性设计、光学成像、同步硬件和现场工艺验证。详细提炼见 `references/framework.md`。
