# 《Machine Vision Algorithms and Applications》方法论

## 什么时候用我

- 机器视觉项目立项、打样、方案评审。
- 光源、镜头、相机、标定、传统算法、3D 和检测任务需要整体取舍。
- 从 PoC 走到现场上线，需要补齐工业边界。

## 核心框架

### 1. 成像优先闭环

步骤：
1. 定义被检测的物理事实：缺陷、边、孔、码、字符、尺寸、公差。
2. 设计成像：光源、镜头、相机、FOV、分辨率、曝光、景深、运动。
3. 再选算法：分割、滤波、形态学、边缘、匹配、测量、OCR、3D 或学习方法。
4. 验证闭环：误检、漏检、节拍、鲁棒性、可维护性。

### 2. 几何测量与定位精度链

像素精度不等于真实精度。必须把标定、畸变、姿态、亚像素、机械重复性和结果通信连起来看。

### 3. 应用模式路由

- 存在/缺失、计数：分割、Blob、形态学。
- 边缘/尺寸：边缘、亚像素、标定、测量模型。
- 位置/姿态：模板匹配、特征匹配、几何验证。
- OCR/读码：专用 OCR/码制工具优先。
- 表面缺陷：纹理、异常检测、光源策略、样本闭环。
- 3D：结构光、双目、点云、表面模型、标定。

## 决策规则

1. 如果图像没有稳定突出目标特征，就不要先比较算法。
2. 如果最小特征像素数不足，软件调参不能弥补采样缺陷。
3. 如果结果要用真实单位或机器人坐标，必须做标定和坐标链验证。
4. 如果工件姿态会变，先定位/配准，再检测和测量。
5. 如果缺陷定义来自工艺和质量标准，先把 OK/NG 边界变成样本和规则。
6. 如果阈值只能在少数样图上成立，不能进入验收。
7. 如果 3D 方案不说明遮挡、反光、基线、精度链和标定维护，不应上线。
8. 如果算法选择依赖厂商库，必须记录版本、算子、参数和可迁移性。
9. 如果现场会换型，参数管理和换线流程是方案的一部分。
10. 如果系统要量产，必须保留失败图像和回放集。

## 检查清单

- [ ] 被检测物理事实和误判代价明确。
- [ ] 光源、镜头、相机、FOV、分辨率、曝光、景深已计算。
- [ ] 样本覆盖良品波动、已知不良、边界品和现场脏变量。
- [ ] 坐标、标定、畸变、机械重复性和通信链路已验证。
- [ ] 节拍包含采集、处理、通信、PLC/机器人动作。
- [ ] 失败图像和版本参数可以回放复盘。

## 反模式

- 先算法后光学。
- 用单张效果图证明方案。
- 固定 ROI 硬扛姿态变化。
- 把实验室样本当现场验收集。
- 不记录参数和失败图像。

## 边界

该方法论贴近工业机器视觉基础框架，但不替代 HALCON、Cognex、OpenCV 或具体相机厂商当前文档。详细提炼见 `references/framework.md`。
